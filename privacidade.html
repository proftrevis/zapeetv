Política de Privacidade

Esta política explica como o aplicativo ZapeeTV usa dados ao acessar o YouTube.

Quem usa o aplicativo

O ZapeeTV é uma ferramenta interna, usada somente pelo dono do canal ZapeeTV para enviar e gerenciar os vídeos do próprio canal. Ele não é oferecido ao público.

Dados acessados

Com a autorização do dono da conta, o aplicativo usa a API de Dados do YouTube para enviar vídeos, definir título, descrição, tags e privacidade, e ler informações básicas do canal. Não acessamos dados de outros usuários nem de espectadores.

Como os dados são guardados

O token de acesso fica guardado em um armazenamento privado, usado apenas para publicar os vídeos do canal. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Serviços do Google

O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. Ao usar o YouTube, também se aplicam os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Contato

Dúvidas podem ser enviadas pela página do canal no YouTube: youtube.com/@zapeetv.
